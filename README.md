# Shubhankar Rahul Chavan — Portfolio

Premium static portfolio website. Open `index.html` in any browser — no server, no build, no dependencies required.

## Quick Start

1. Open the project folder
2. Double-click `index.html`
3. Website opens in your browser

## File Structure

```
├── index.html          # Main entry point
├── style.css           # All styles
├── script.js           # All functionality
├── assets/
│   ├── profile.jpg     # Profile image (replace with your photo)
│   ├── profile.svg     # Placeholder profile image
│   └── resume.pdf      # Resume file (replace with your resume)
└── README.md
```

## Customization

### Profile Image
Replace `assets/profile.jpg` with your own photo. The website will display it if present, otherwise shows initials.

### Resume
Replace `assets/resume.pdf` with your actual resume file. The download button will automatically use it.

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript
- No frameworks, no build tools, no CDN dependencies

## Features

- Responsive design (mobile, tablet, desktop)
- Smooth scroll navigation
- Project filtering
- Animated network background
- Scroll reveal animations
- Accessibility support
- `prefers-reduced-motion` support

## Deployment

This is a static website. Deploy to any static hosting:

- **Vercel**: Upload the folder as a static site
- **Netlify**: Drag and drop the folder
- **GitHub Pages**: Push to a repo and enable Pages
